# Learn Python

This repository contains code examples and exercises for learning Python.

## What's Included

- **Basic Concepts**: Variables, loops, and functions.
- **Data Structures**: Lists, dictionaries, sets, and tuples.
- **Object-Oriented Programming**: Classes, inheritance, and polymorphism.
- **File Handling**: Reading and writing text and binary files.
- **Error Handling**: Robustness using try, except, and finally blocks.
- **Standard Library**: Exploring built-in modules like os, sys, and math.
- **Algorithms**: Common sorting and searching algorithms.
- **Etc.**: Other useful Python programming concepts.
